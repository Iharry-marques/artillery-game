# godot/

Raiz do projeto Godot 4.x (`res://`). O `project.godot` ainda não foi criado (Godot não instalado em 06/10/2026).

| Diretório | Conteúdo |
|---|---|
| `scripts/` | GDScript. Planejado: `core/` (simulação pura, sem Node), `game/` (nós de gameplay), `presentation/` (visual, HUD, câmera) |
| `scenes/` | Cenas `.tscn` |
| `assets/` | Assets próprios (placeholders procedurais primeiro, arte do pipeline Blender depois) |
| `shaders/` | Shaders próprios |
| `tests/` | Testes executáveis em modo headless (calibração balística em primeiro lugar) |

Veja [../docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).
